# 0.1.1 验收记录

日期：2026-11-25。

## 自动验证

`npm test` 的 10 项测试全部通过，覆盖轨道和 API；`npm run typecheck`、`npm run build` 通过，覆盖 TypeScript 与 Next.js 生产构建。

## 实际浏览器

- 生产服务启动于 localhost:3000，五个页面可访问。
- WebGL 地球真实渲染本地地理轮廓，卫星可通过下拉选择。
- 控制台播放按钮切换为暂停；地球轨道与时间轴共用轨道数据。
- 北京 + 星链分析返回 38 个窗口；默认上海分析返回 72 个窗口。
- CSV 与 JSON 按钮实际下载文件；刷新后保存的北京任务仍存在。
- 最低仰角 90° 时正确显示空态。
- 文档的“运行本地请求”实际返回 synthetic-demo JSON。
- 1440px 桌面与 390px 手机截图检查；手机菜单可打开并导航。
- 验收发现表单轨道最小内容宽度导致横向溢出，增加 minmax(0,1fr) 和控件 min-width:0。
- 验收发现 30 秒窗口显示为相同分钟，加入秒级显示和回归测试。
- 修复后 390px 视口的文档宽度为 375px（含滚动条），不再横向溢出；30 秒窗口实际显示为 08:08:00—08:08:30。
- 60 倍速播放后，时间从 08:00:00 推进至 08:06:00，时间轴数值为 360。
- 浏览器未捕获页面级 error 日志。CSV/JSON 下载内容已读取确认。

## 边界

不包含真实星历、测量接收与定位解算；WebGL 的异常处理提供文字降级，但未在物理禁用 GPU 的独立设备上验收。
