# Starlink Implementation Plan

**Goal:** 仅用真实 Starlink GP/TLE 做 SGP4 与机会导航几何分析。
**Architecture:** 服务端源适配与缓存，纯 TS 轨道/分析模块，浏览器 Worker，三维全量点云，共用快照上下文。
**Tech Stack:** Next.js, TypeScript, Three.js, satellite.js, undici。

1. 编写并运行缺失功能测试：解析过滤、校验、SGP4 基准、DOP、窗口和缓存。
2. 实现 `src/lib/starlink.ts`、`catalog-parser.ts`、`catalog-store.ts`、`catalog.ts` 和同步/导入 CLI；验证真实全量来源。
3. 新建 `/api/starlink/catalog`、`/api/starlink/opportunities`；旧演示 API 返回 410，不再输出合成卫星。
4. 共享 CatalogProvider，Web Worker 分析，重做控制台全量点云与选中轨迹、分析报告和可追溯导出。
5. 更新技术页面、接口文档、README；删除旧合成模型；验证测试、类型、构建和实际浏览器。
6. patch 递增、更新日志、提交。
