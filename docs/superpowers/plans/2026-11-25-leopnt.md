# leopnt Implementation Plan

**Goal:** 完成中文可独立运行的机会导航服务演示网站。

**Architecture:** Next.js 提供页面与本地 API，纯 TS 模块负责演示轨道和窗口分析，Three.js 客户端视图复用同一位置函数。资源随项目分发，浏览器本地保存任务。

**Tech Stack:** TypeScript, Next.js, React, Three.js, lucide-react, node:test, Playwright。

## Global Constraints
- 全中文产品界面；合成数据明确标注；无外部运行服务依赖。
- 使用批准的 spacelibre SVG 和完整配色角色。
- 在新建项目分支顺序实现，不委派子代理。
