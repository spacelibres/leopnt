# leopnt 中文独立运行版本

用户已批准官网与交互平台方案，并要求直接完成中文独立运行版本。

## 范围
首页、三维控制台、机会分析、技术能力、开发文档五个页面。TypeScript、Next.js App Router、Three.js；本地资源，无密钥、数据库或外部请求运行依赖。

## 交互与数据
72 颗合成卫星，三组演示星座。圆轨道模型包含地球自转；按观测位置、时间、最低仰角、星座计算六小时内机会窗口。三维视图支持旋转缩放、卫星选择、轨道开关、暂停、倍速、时间轴。分析可导出 CSV 和 JSON，保存任务到浏览器。所有轨道、结果和 API 明示演示模型，不声称真实服务或定位精度。

## 视觉
深空底、电光蓝轨道、红橙辅色和浅黄强调色。使用 spacelibre electric-orbit 完整角色；采用官方 SVG 图形与 monochrome 白色字标；产品名称 leopnt 独立文本。连续轨道位于内容后方，Arial 与中文系统字体，等宽数字。手机重排导航和分析控件。

## 验收
轨道几何、仰角、边界校验与窗口过滤单元测试；浏览器验证导航、筛选、导出、时间播放、窄屏与 WebGL 降级；TypeScript 与生产构建通过。README 说明启动和模型局限。验证后 patch 升级并提交 git。
